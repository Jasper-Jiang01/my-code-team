# ⛔ 规划模式（plan）已下线

> **本文件为规划模式下线说明文档，请勿再参考 [plan.md](plan.md) 执行任何规划操作。**

## 下线声明

**规划模式（plan 模式）已正式下线，不再对外提供服务。**

下线范围包括：
- `plan` 子命令
- `confirm_plan` 子命令
- `--replan` 参数
- 所有与规划会话相关的流程（新建规划会话、确认执行、修改方案等）

## 用户触发时的处理规则

当用户在任何时候提到以下关键词，必须**立即告知用户规划模式已下线**，不得尝试执行任何规划相关操作：

- 「规划」、「规划模式」、「plan 模式」
- 「制定方案」、「规划分析步骤」、「规划一下」
- 「确认执行」（在规划上下文中）、「修改计划」（在规划上下文中）

**必须回复用户的内容：**

> ⚠️ **规划模式已下线，不再提供此功能。**
> 如需分析，请直接描述您的分析问题，我将为您使用**分析模式（analyze）**进行处理。
> 如有疑问，可前往 https://ba-ai.sankuai.com 查看最新功能。

## 严禁行为

- **严禁**调用 `plan`、`confirm_plan` 子命令
- **严禁**向子 agent 下发任何规划相关 task
- **严禁**读取或引用 `/tmp/ba_plan_*.json` 规划缓存文件
- **严禁**以任何替代方式模拟规划功能（如自行拆解步骤、生成分析计划等）
